# Pattern Master – Pattern Printing Generator 🚀

An ultra-modern, interactive web application built for programming students and enthusiasts to master loops, conditional logic, spatial alignment, and pattern printing across multiple programming languages.

## ✨ Key Features
1. **Interactive Pattern Studio**: Over 35+ dynamic patterns (Star, Number, Alphabet, Binary, and Special matrices).
2. **Real-time Live Preview**: Instantly updates pattern output and metrics as you change rows, columns, or symbols.
3. **Multi-Language Solutions**: View code implementations in **Python, C, C++, Java, and JavaScript**.
4. **Code & Pattern Exporters**: One-click **Copy to Clipboard** and **Download as .TXT / Source files**.
5. **Logic & Complexity Breakdown**: Detailed algorithmic explanation with Time and Space complexity breakdowns ($O(N^2)$, $O(1)$, etc.).
6. **Favorites Storage**: Bookmark your favorite patterns using browser `localStorage`.
7. **Dark / Light Mode**: Seamless glassmorphic theme switcher with neon accents.

## 🛠️ Technologies Used
- **HTML5** (Semantic structure)
- **CSS3** (Glassmorphism, CSS Grid/Flexbox, Custom variables, Smooth transitions)
- **Vanilla JavaScript (ES6+)** (Dynamic pattern rendering engine, event handling)
- **FontAwesome & Google Fonts (Inter & Fira Code)**
